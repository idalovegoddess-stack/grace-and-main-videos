# Grace and Main Press — book videos

Finished promo videos for Ida Shoulders' books. This folder is public so Buffer can fetch the videos.

Every morning the refill robot (`refill.py`) tops up the TikTok queue in Buffer from the approved posts in `posts.json`, and records what it sent in `posted.json`. Only posts marked `"ready": true` go out; Ida approves each batch before it is marked ready.
